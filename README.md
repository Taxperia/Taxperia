## About

I am building practical software around productivity, automation, desktop utilities, and Windows experience improvements.

My work usually starts from a simple question: **"Can this annoying repeated task become a clean tool?"** Then I turn it into something usable, visual, and easy to run.

- Building under the **Miyotu** name
- Focused on **Python desktop apps**, **JavaScript/Electron tools**, and **workflow automation**
- Interested in useful AI-assisted development patterns, especially around **Codex skills**
- Shipping small, focused projects instead of letting ideas stay as notes
